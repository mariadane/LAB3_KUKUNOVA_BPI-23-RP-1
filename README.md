# Лабораторная работа № 3 — Кукунова Мария

## Запуск
Распакуйте архив. Откройте index.html в современном браузере с доступом к интернету при подключенном VPN.
Все три файла index.html, style.css и app.js должны находиться в одной папке.
Альтернативный запуск: откройте папку в VS Code и запустите index.html через Live Server.
Установка библиотек, серверная часть и база данных не требуются.

## Реализация
- HTML-интерфейс, адаптивный CSS, отдельный app.js без фреймворков.
- GET пяти записей через fetch, async/await и response.json().
- POST JSON {title, body, userId: 1}, Content-Type: application/json.
- Валидация trim(), addEventListener и preventDefault().
- Проверка response.ok, try/catch/finally, сообщения и блокировка кнопок.
- Отображение данных через textContent и DOM без перезагрузки.
- Созданная запись показывается отдельно и не исчезает при повторной загрузке списка.
- JSONPlaceholder не сохраняет новые записи постоянно.

## Проверка
1. Нажать «Загрузить публикации»: пять карточек с заголовком и текстом, сообщение об успехе.
2. Отправить пустые поля, затем поля с пробелами: ошибка; в Network нет POST.
3. Ввести «Моя первая публикация» и «Проверка POST-запроса»: карточка с заголовком, текстом и ID ответа; сообщение об успехе (обычно HTTP 201).
4. В app.js временно заменить GET_URL на https://jsonplaceholder.typicode.com/postz. Нажать загрузку: ошибка HTTP 404, кнопка снова доступна. Вернуть исходный URL и повторить загрузку.
5. В DevTools → Network включить Offline: запрос завершится понятной ошибкой; кнопка снова доступна. Вернуть No throttling и повторить.
6. Вставить в заголовок <b>Тест</b>: текст должен выводиться буквально, а не как HTML.
